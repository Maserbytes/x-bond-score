How to Install in 60 Seconds

Simple step-by-step instructions for desktop and mobile browsers.

1

Chrome / Edge / Brave

1. Download and extract bondscore-production.zip.
2. Open chrome://extensions (or edge://extensions).
3. Turn on Developer Mode in the top right.
4. Click Load unpacked and select the extracted folder.

2

Android (Kiwi Browser)

1. Install Kiwi Browser from Google Play Store.
2. Open kiwi://extensions.
3. Toggle Developer mode.
4. Click + (from .zip) and pick the downloaded ZIP file.

3

Android (Firefox Mobile)

1. Install Firefox and add the Tampermonkey add-on.
2. Click the Install Userscript (.user.js) button above.
3. Confirm "Install" in Tampermonkey. It runs automatically on X!
