# BondScore v1.4.0 Release Notes

**Version:** 1.4.0  
**Release Date:** November 15, 2026  
**Author:** @MaserSuspended  

---

### 🌐 Multi-Platform Relationship Layer
BondScore expands from X (Twitter) into a unified cross-platform relationship intelligence layer supporting:
1. **X (Twitter)** — Core platform (Timeline + DMs tracking **ON** by default).
2. **Threads (`threads.net`)** — Feed interaction detection, profile badges, and direct messaging metadata (**OFF** by default).
3. **Bluesky (`bsky.app`)** — AT Protocol timeline observation, profile headers, and chat metadata (**OFF** by default).

### ⚙️ Independent User Controls & Settings
- **Master Platform Toggles:** Turn tracking on/off per platform independently.
- **Granular Feature Toggles:** Independent switches for Timeline interactions vs. Direct Messages for each network.
- **Unified Platform Filter Bar:** Switch seamlessly between "All Platforms", "X", "Threads", and "Bluesky" in the popup dashboard.

### 📱 Apple iOS Frosted Glass UI (Glassmorphism)
- **True Apple Glassmorphism:** Cards and modals crafted with `backdrop-filter: blur(24px) saturate(190%)`, specular inner borders (`inset 0 1px 0 rgba(255, 255, 255, 0.22)`), and smooth cubic-bezier micro-interactions.
- **Native iOS Toggle Switches:** Capsule sliders featuring Apple iOS Active Green (`#34C759`) and smooth spring response.
- **Segmented Platform Pills:** Frosted pill selectors with tactile active states and platform-specific accent hues.

### 🔒 100% Local-First & Zero Content Privacy
- Absolute adherence to local-first architecture (`chrome.storage.local`).
- Zero data leaves the user's device.
- **Never reads or stores DM message bodies**; only metadata (timestamps, direction, frequency, reply latency, participants) is processed.
- Modular Manifest V3 adapters that only observe active networks when enabled.
