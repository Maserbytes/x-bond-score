# BondScore v1.1.3

## What's fixed

- Reads profile pictures from the avatar container for the matching X account, instead of taking the first profile image on the page. This prevents the signed-in user's sidebar photo from being saved for other people.
- Refreshes a stored contact's display name or avatar when the X profile data changes, even when follow signals stay the same.
- Debounces relevant dashboard updates, ignores unrelated storage changes, and discards stale overlapping leaderboard loads to stop repeated list redraws.
- Coalesces orbit-canvas redraws while mutual avatars finish loading.
