# BondScore v1.1.2

## What's new

- Adds a bounded, one-time seven-day history catch-up when a profile is first visited. It retries after 24 hours if X does not return a usable search response.
- Records inbound and outbound replies, likes, quotes, and mentions separately, and repairs directional totals from the local event ledger.
- Keeps the event ledger while scores remain steady for five inactive days, then decay with the configured exponential half-life (14 days by default).
- Removes the old previous-score floor that prevented scores from decaying.

## Limits

History catch-up depends on posts and notifications X exposes to the signed-in session. It cannot recover every interaction, including all historical likes. Event data remains local to the extension.
