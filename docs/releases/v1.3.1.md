# BondScore v1.3.1 - Persistent Chat Memories & Lifetime Ledger Release

A critical update ensuring permanent chat memories, lifetime message counting, deep DOM thread ingestion, and 100% protection against zeroing out on page refresh or opening after days of inactivity.

## 🌟 What's New in v1.3.1

### 1. 💭 Chat Memories & Milestones System
- **Lifetime Conversation Memory Ledger**:
  - Permanently records all chat exchanges ever since the extension has been active.
  - Non-decreasing lifetime counters: `lifetimeSent`, `lifetimeReceived`, and `lifetimeTotal` that are **never reset or decayed**.
  - **Memory Milestones**: Automatically logs historical milestones into each conversation's memory ledger:
    - 🌱 **Chat Established**: Records the exact date BondScore first discovered the chat connection.
    - 💬 **Volume Checkpoints**: Celebrates passing 10, 25, 50, 100, 250, 500, and 1,000 lifetime messages exchanged.
    - 🔥 **Streak Records**: Preserves all-time longest daily messaging streaks (`Longest Streak Record: Xd`).
    - 👑 **Rank Promotions**: Chronological logs of promotions (e.g. "Promoted to Bestie on Nov 15").
- **Interactive In-Page Memories Card**:
  - Embedded inside the DM Scorecard modal (`openDmScoreCard`).
  - Displays lifetime stats grid (Memory Since, Lifetime Messages, Peak Relationship Rank, Longest Streak).
  - Chronological **Memories Timeline** showcasing milestones with icons and timestamps.
- **Popup "Chat Memories & Milestones" Section**:
  - Dedicated section under `💬 DMs & Groups` displaying all-time chat champions by lifetime volume and recent milestone moments.
  - New filter pill: `💭 Memories` for one-click access.

### 2. 🛡️ Never-Zero Refresh & Startup Protection
- **Deep DOM Thread Ingestion**:
  - When opening any message thread on X (`/messages/...`), BondScore scans all rendered messages (`[data-testid="messageEntry"]`), determines directionality (outbound vs inbound), and indexes them into the conversation memory ledger.
  - **Deduplication Engine**: Unique message fingerprints prevent double-counting upon page reloads or DOM mutations.
- **Passive Inbox Ingestion**:
  - When browsing `/messages`, every visible conversation row is automatically registered in storage with its preview message and metadata, so conversation cards and row badges never show empty "0" on initial discovery.
- **Multi-Day Grace Period on DM Recency**:
  - Added a **3-day grace period** before recency decay applies to private conversations.
  - Opening the extension after a day or two will no longer cause bond scores to artificially plummet to 0.
  - Added **Memory Baseline Protection**: Conversations with high exchange history maintain a guaranteed baseline connection level.
- **Account Scoping & Resolution Resilience**:
  - Fixed account key resolution to prevent fallback to empty `'you'` namespace on page reload.
  - Added multi-key lookup fallbacks across scoped `acc:<account>:dm:` and un-scoped `dm:` records so chats are never lost between account switches.
